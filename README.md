# SpeakPro AI

AI-powered public speaking learning app for selected HUMSS students.

## Screens included
- Splash screen
- Login screen
- Register screen
- Landing page
- Feature selection
- Public speaking flow
- Vocabulary flow
- Pronunciation flow
- Progress tracking

## Run project
```bash
flutter pub get
flutter run
```

## Features
- Student-friendly UI
- Practice selection
- AI prompt flow
- Recording pages
- Feedback pages
- Progress dashboard
